# Portfolio Site

Personal portfolio site for Jaiden Jakubowski. This site hosts a resume, links to GitHub/LinkedIn, and showcases projects.

**Live site:** https://jaidenjaku.github.io/portfolio-site/

## Tech stack

- Flask (local development)
- HTML5 UP "Miniport" template, customized
- Custom CSS (Color Hunt blue palette: `#e3f2fd`, `#90caf9`, `#2196f3`, `#0d47a1`)
- Deployed as a static site via GitHub Pages

## Features

- **Home** — intro, headshot, GitHub/LinkedIn/email links
- **Skills** — languages, cloud & infrastructure, testing & data, tools & systems
- **Projects** — project cards with screenshots, tech stack badges, and GitHub links
- **Education** — Ursinus College, The John Carroll School, Python Programming Course (Udemy)
- **Resume** — downloadable PDF with an embedded viewer
- Custom favicon, SEO meta tags, and Open Graph tags for link previews


## Deployment

This site is static (no dynamic routes or backend logic), so it's deployed directly via **GitHub Pages:**

`main.py` / Flask is kept in the repo for local development and editing convenience, but isn't used in production.
